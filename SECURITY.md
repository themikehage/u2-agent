# Security Policy

## Supported Versions

Security fixes and patches are applied to the following release lines:

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability or sensitive security issue in `u2-agent`, please **do not open a public issue**.

Instead, please send an advisory email directly to:
**security@therry.dev**

Please include:
- A detailed description of the vulnerability.
- Steps to reproduce or proof-of-concept payload/code.
- Impact on local environments or remote devices.

We acknowledge receipt within 48 hours and work on a coordinated security patch before public disclosure.
