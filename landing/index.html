Sub-15ms Loop

How the 3-step agent loop works

Zero token overhead, predictable deterministic error codes, and warm background sessions.

01

Semantic Snapshot

u2-agent ui snapshot strips frame containers, merges overlapping ghost wrappers, and indexes every interactive button, input, and item with an ephemeral reference handle (@1, @2, ...).

$ u2-agent ui snapshot
02

Sub-15ms Cached Tap

The LLM issues an action specifying --ref "@N". The background daemon resolves exact screen coordinates directly from RAM in sub-15ms without cold re-dumping or ADB disconnects.

$ u2-agent ui tap --ref @1
03

Clean Stream Separation

stdout emits strictly compact machine text (ok or snapshot trees). Diagnostics, self-healing hints, and audit logs flow to stderr, preventing agent reasoning contamination.

ok
Core Invariants

Engineered for agent autonomy

Strictly adhering to the architectural rules defined in AGENTS.md.

⚡

Zero Heavy Dependencies

Crafted purely with Bun and native TypeScript APIs. No bulky WebDriver dependencies, Puppeteer emulators, or Java runtime wrappers on the host.

🚀

Persistent Hot Daemon

Keeps ADB socket forwards and UIAutomator2 JSON-RPC sessions alive in the background, slashing per-action execution latency from 800ms to under 15ms.

🧠

Semantic Deduplication

Automatically collapses nested ghost wrappers with ≥ 85% bounding box overlap into single high-level semantic components (Input, Button, Tab, Toggle).

🤖

Universal Model Support

Drop-in compatible with Claude Code, OpenCode, Cursor, Antigravity, AutoGen, and custom Python / LangChain agent orchestration loops.

🔧

Tool Schema Discovery

Export standard function-calling schemas with tools schema --format openai ready to plug into Anthropic, OpenAI, or Gemini tool call catalogs.

🛡️

Deterministic Recovery

Every failure emits distinct machine error codes (SELECTOR_NOT_FOUND, DEVICE_OFFLINE, USAGE) accompanied by actionable recovery hints on stderr.

        Quick Start
        
Up and running in 2 minutes

        

          All you need is Bun and an Android device with USB debugging enabled.
        

      


      

        

          

            1
            Clone and install
          

          
Clone the repository and install dependencies with Bun:

          

            git clone https://github.com/themikehage/u2-agent.git && cd u2-agent && bun install
            
          

        


        

          

            2
            Provision target device
          

          
Verify your connected device and install the lightweight UIAutomator2 RPC server:

          

            bun run src/index.ts setup install
            
          

        


        

          

            3
            Inspect and interact
          

          
Take your first compact semantic snapshot and tap elements by handle:

          

            bun run src/index.ts ui snapshot
            
          

        


        

          

            4
            (Optional) Compile standalone executable
          

          
Build a single self-contained binary without needing Bun on PATH:

          

            bun run build
